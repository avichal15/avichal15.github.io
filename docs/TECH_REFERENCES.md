## Required citation/verification discipline
- Use official docs for tool/API behavior and current export settings.
- Inspect the live website and repository at execution time. Mark blocked/private/unreachable URLs instead of inferring their contents.
- If more tooling is introduced, add its official documentation URL and explain why it is needed.
- Do not upload the owner’s private character sheet, certificates, credentials or project source to external services to get an answer.
